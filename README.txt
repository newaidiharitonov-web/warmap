КАРТА СОБЫТИЙ — ИНСТРУКЦИЯ

Что внутри (все файлы лежат плоско, без вложенных папок — так проще загружать с айфона):
- index.html — страница карты
- app.js — логика; список типов событий задается в блоке TYPES
- data/versions.json — список дат
- data/events-2026-11-25.geojson — события за 25.11.2026 (пример)

КАК ДОБАВИТЬ НОВУЮ ДАТУ:
1. В папке data создайте файл events-2026-11-26.geojson (формат ГГГГ-ММ-ДД)
2. Скопируйте в него содержимое прежнего файла и отредактируйте точки
3. Добавьте дату в массив dates в data/versions.json — последняя в списке показывается по умолчанию

КАК ДОБАВИТЬ СОБЫТИЕ (в events-<дата>.geojson):
{
  "type": "Feature",
  "properties": {
    "type": "strike",        // strike | shelling | clash | drone | movement | info
    "title": "Что произошло",
    "desc": "Подробности",
    "time": "время суток"
  },
  "geometry": { "type": "Point", "coordinates": [ДОЛГОТА, ШИРОТА] }
}
Внимание: сначала ДОЛГОТА, потом ШИРОТА. Не забудьте запятую между объектами в массиве features.

Координаты места можно взять в приложении Карты: долгое нажатие по точке -> Поделиться.
